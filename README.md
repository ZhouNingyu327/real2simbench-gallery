# Real2SimBench

八个刚体与布料物理泛化场景，47段GT展示视频，以及逐项更新的GPT输出和GT/GPT对照。

抽桌布替换旗帜：展示完整REF、T_OBS、T_FUTURE、A快拉和V新视角。严格E视频待完整独立验收。已完成的GPT T/A/V视频先行展示，分数逐项更新。

静态网页无需构建。完整数值GT、模型会话、凭据与服务器信息不在此仓库中。数据独立制作，非4DCodeBench官方发布。Newton、PPF和Codim-IPC代码许可见licenses目录。


## Physical generalization research cases

The research/ section adds nine separately described native-solver research cases (36 REF/A/E/V display clips) plus one tablecloth model-prediction failure observation. The existing eight-scene gallery and original evaluation records retain their previous scope. Case status, source versions, GT boundaries and numerical limitations are stated individually. Public downloads contain display media and descriptions only, not native GT or hidden evaluation configurations.
